# Naresh Swami Portfolio

A responsive, modern dark-theme portfolio built with plain HTML, CSS and JavaScript.

## Run locally
1. Extract the ZIP.
2. Open `index.html` in your browser.

No build tools or framework required.

## Personalize before publishing
- Replace `YOUR_EMAIL@example.com` in `index.html` with your email address.
- Replace the LinkedIn, GitHub and HackerRank profile links with your actual profile URLs.
- Add project repository/demo links and more precise project descriptions.
- Confirm the skills and experience descriptions reflect your actual work.
- Add your resume PDF link if you want a downloadable CV button.

## Deploy
You can host this static site using GitHub Pages, Netlify, or any static web hosting provider.
